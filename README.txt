Cool Beauty VS Cute Bunny - take1
=================================

双击 CoolBeauty VS CuteBunny.exe 开始。
internal 文件夹必须和 exe 放在同一层，不要单独移动 exe。

操作
----
WASD / 方向键   移动
Shift           冲刺
空格（按住）    摆 POSE / 回 COOL
E               互动、照镜子、开弹窗、出门
Q               扔胡萝卜
P               暂停
R               重开本关
F1              CRT 扫描线开关
F12             截图
M               静音
Esc             退出

流程
----
L0 化妆间 -> L1 海滩 -> L2 录音室 -> L3 虚拟空间

每关找齐 3 件东西，去右侧标着 EXIT 的门，按 E 或直接走进去。
过关后按 ENTER 进入下一关。被兔兔抓到会重开本关。
L3 通关后根据 CUTE 值进入普通结局或真结局。
